# F7｜Cross-System Synthesis and Judgment Revision / 跨系统综合与判断修正

F7 is the observatory's durable synthesis layer. It consumes bounded findings from F1–F6, reconciles definitions/dates/status, removes duplicate source lineages, surfaces conflicts, and produces calibrated cross-system interpretation.

F7 is not an additional source class and does not create stronger evidence merely by combining prose.

## Synthesis responsibilities

- normalize entity/version/date/status vocabulary across workstreams;
- identify whether apparently independent findings share the same underlying source lineage;
- distinguish convergence in evidence from repetition in reporting;
- preserve counterevidence and unresolved conflicts rather than averaging them away;
- compare capability, infrastructure, agentic-system, evaluation/governance, and ecosystem implications without collapsing their evidence types;
- state which part of a judgment changed and what evidence caused the revision.

## Evidence independence

```text
same source cited by multiple workstreams != multiple independent sources
weekly/monthly inheritance != new corroboration
vendor claim + articles quoting vendor != independent triangulation
repository analysis != external fact
```

When independent evidence exists, name what makes it independent: different primary source, implementation, measured population, regulatory record, or genuinely separate observation surface.

## Conflict handling

If sources disagree:

1. identify exact propositions and versions/dates;
2. compare authority for that proposition;
3. determine whether the disagreement is factual, temporal, definitional, methodological, or analytical;
4. retain unresolved dimensions explicitly;
5. narrow the synthesis to the strongest common supported statement when resolution is impossible.

`UNCERTAIN` or a bounded non-conclusion is a valid synthesis result.

## Fresh-search boundary

F7 normally synthesizes F1–F6 rather than becoming an eighth search stream. A fresh source check is justified only when required to resolve a material identity/date/status conflict; any such source is recorded with normal methodology/provenance rules rather than treated as synthesis authority by default.

## Output discipline

A durable synthesized judgment should expose:

- proposition and scope;
- contributing workstreams;
- source/evidence lineage;
- status/maturity and relevant dates;
- supporting and counter evidence;
- what is observation versus observatory analysis;
- confidence/uncertainty stated qualitatively and evidence-specifically rather than as invented probability;
- explicit non-claims;
- reason for any judgment revision.

## Relationship to periodic outputs

Periodic Daily/Weekly/Monthly artifacts may use F7 synthesis, but their cadence, closure, and production rules live in separate SOPs. This file defines the stable synthesis responsibility only.

F7 must not rewrite earlier time-scoped observations merely because later evidence changes the current judgment.
