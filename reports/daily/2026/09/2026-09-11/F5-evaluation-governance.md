# F5 — Evaluation / Safety / Governance / Standards

## 2026-09-11

The SG17 secure Agentic AI workshop programme explicitly names security testing, formal verification, runtime audit and security metrics. This strengthens vocabulary visibility only; a workshop programme is not a normative evaluation/recovery contract.

MCP `SEP-2663` remains `Final` as an extension proposal while the extension is described as incubating/evolving toward possible future core-protocol promotion. NIST NCCoE `Software and AI Agent Identity and Authorization` remains `Reviewing Comments`.

Boundary: `Protocol Publication != Operational Maturity`; `Admission != Continuous Authorization`.
