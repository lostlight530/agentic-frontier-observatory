## 0｜Executive Judgment / 核心判断

### 中文

今天没有必要为了 8 月 10 日这个日期强行寻找“凌晨刚发布的新模型”。真正值得记录的是一个刚刚跨过明确截止日期的产品结构变化：OpenAI 官方此前宣布 Atlas 将于 **2026 年 8 月 9 日停止工作**，并明确说明其浏览器型智能体能力正在并入 ChatGPT 与 Codex

这与 Google 6 月已经完成的另一个动作形成同方向信号：computer use 不再只存在于独立的 Gemini 2.5 computer use model，而被内置进 Gemini 3.5 Flash，成为主模型可直接调用的行动能力

两条线放在一起，今天的核心判断是：**Agentic capability 正从“独立 Agent 产品壳层”回流为核心模型与平台的原生能力，而真正长期分化的部分正在上移到 Harness、企业上下文、权限、评测、协议与治理层**

这并不意味着独立 Agent 产品会消失，也不意味着 MCP、A2A 等协议重要性下降。恰恰相反，当 browser use、computer use、tool use 越来越原生，跨平台连接、身份授权、可靠性证据与人工升级机制反而更加重要

### English

There is no reason to manufacture a same-day model headline before the 05:49 CST cut-off. The material signal is a product-architecture transition that crossed a precise date: OpenAI had scheduled Atlas to stop working on **9 August 2026**, while explicitly moving browser-based agentic capabilities into ChatGPT and Codex.

Google had already moved in the same architectural direction by integrating computer use directly into Gemini 3.5 Flash instead of keeping it only as the standalone Gemini 2.5 computer-use model.

The resulting judgment is structural: **agentic action is increasingly becoming a native capability of core models and product surfaces, while durable differentiation shifts toward harnesses, enterprise context, authorization, evaluation, protocols, and governance.**

## 2｜Critical Development: Agentic capability moves inward / 智能体能力向核心平台回流

**FACT** — OpenAI's official ChatGPT release notes state that Atlas was scheduled to stop working on 9 August 2026 and that browser-based agentic capabilities are being brought into ChatGPT and Codex

**FACT** — Google announced on 24 June 2026 that computer use became a built-in tool in Gemini 3.5 Flash; Google explicitly contrasted this with the previously standalone Gemini 2.5 computer-use model

**ANALYSIS** — Browser/computer control is moving from being a product category into being a platform primitive

The historical analogy is not “agents disappear.” It is closer to what happened when capabilities such as web search, multimodality, code execution, and tool calling moved from separate demos into general-purpose AI surfaces

## 3｜What remains outside the core model / 哪些层仍然无法被模型本身吞掉

Native action capability does not solve:

```text
Which tool or agent should be discovered
→ Which identity is acting
→ Who delegated authority
→ What scopes apply
→ How actions are traced
→ How failure is recovered
→ When a human must approve or take over
```

MCP's 2026-07-28 revision strengthens production HTTP behavior and authorization while its Enterprise-Managed Authorization extension addresses organization-level access provisioning

A2A separately standardizes agent discovery and collaboration through Agent Cards and maintains an Inspector and Technology Compatibility Kit for implementation checking

NIST/NCCoE continues to frame identification, authorization, auditing, non-repudiation, and prompt-injection controls as open enterprise adoption questions

**ANALYSIS** — As action becomes native, trust infrastructure becomes more visible rather than less important

## 4｜Production agents require policy and escalation / 生产 Agent 需要政策与升级机制

OpenAI Presence is useful here not because it is today's release, but because it states the production problem directly: enterprise agents need policies, guardrails, verified performance, approved actions, and escalation to people

This supports a distinction the observatory should preserve:

```text
Agent capability
≠
Agent deployability
```

A system may be able to browse, click, call tools, or coordinate with other agents while still lacking the authority model and evidence needed for consequential production use

## 5｜Workstream Findings / 分任务发现

### F1 History and theory

The current phase looks less like the birth of a new isolated “agent product category” and more like the absorption of agency into general computing interfaces. Historically, mature capabilities often disappear into platforms once they become expected primitives

### F2 Models and algorithms

The model-versus-system distinction remains necessary, but the boundary is moving. Computer use can now be a model-native tool capability, meaning some functions previously assigned to an external harness are moving closer to the model surface

### F3 Infrastructure

The infrastructure question shifts from “can we automate a browser?” toward routing, isolation, session/account state, credentials, audit, policy enforcement, and reliable recovery across web and desktop environments

### F4 Agentic systems

MCP, A2A, Agent Cards, discovery, identity, and authorization become more valuable as core products absorb generic action. Their role is not to make a model click; it is to make independent systems connect and act under explicit boundaries

### F5 Evaluation and governance

The evaluation unit should include not only task success but whether the correct identity acted, within the correct scope, with traceable approvals and escalation behavior

### F6 Ecosystem and society

Product consolidation can simplify user experience while increasing platform concentration. Open protocols and neutral governance therefore remain strategically important even as user-facing agent surfaces consolidate

## 6｜Cross-System Analysis / 跨系统分析

Yesterday's “network appears” stack should now be split into two interacting directions:

```text
INWARD CONSOLIDATION
Model
→ Native computer/browser/tool use
→ Core product surface
→ Harness / workflow / enterprise context

OUTWARD INTEROPERATION
Tool & Data Access
→ Agent-to-Agent Coordination
→ Discovery & Reachability
→ Identity & Authorization
→ Conformance, Evaluation & Observability
→ Governance & Deployment Decision
```

The frontier is therefore not simply “more autonomous agents.” It is a simultaneous **consolidation inward** and **standardization outward**

## 7｜Changed Judgments / 修正的判断

### Refined judgment

Yesterday we treated Harness / Runtime as a stable layer immediately above the model

Today that boundary becomes more fluid: some action capabilities are moving directly into core model/product surfaces, while the harness increasingly concentrates workflow state, context, policy, recovery, and orchestration

### Strengthened judgment

Protocol and identity layers are not made obsolete by native computer use. They become the means by which increasingly capable core surfaces connect without collapsing into one vendor-controlled system

## 8｜Stable Judgments / 稳定判断

- No authoritative same-day release before cut-off justifies inventing a new model trend
- Agent capability cannot be equated with deployability
- MCP and A2A remain complementary to product-level agent surfaces
- Identity, authorization, audit, evaluation, and human escalation remain open infrastructure layers
- Official product transitions must be recorded with exact effective dates, not only announcement dates

## 9｜Uncertainties and Watchlist / 不确定与观察点
