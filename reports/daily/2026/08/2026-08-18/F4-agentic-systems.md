# F4｜Agents, Runtimes, Harnesses, and Protocols

A governed execution path now has three phases:

```text
PRE-EXECUTION
published state → identity → policy → trigger

IN-EXECUTION
prompt → response → tool calls → task state

POST-EXECUTION
audit → SIEM → review → revocation / policy update
```

This is an observatory synthesis, not a universal protocol

**Judgment:** runtime governance requires both authority before action and evidence after action
