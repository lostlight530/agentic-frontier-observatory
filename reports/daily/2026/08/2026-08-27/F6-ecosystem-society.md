# F6 — Ecosystem & Society

The strongest ecosystem pressure appears outside code

A stopped Agent may already have created a document, sent a message, changed a CRM record, modified infrastructure or published data

Those effects often cannot be retracted by terminating the runtime that created them

This strengthens W35 H6:

> non-code autonomous outputs need explicit supersession, withdrawal or compensation semantics

**Boundary:** today’s GitHub revert evidence is code-specific; non-code parity remains open
