# F4｜Agents, Runtimes, Harnesses, and Protocols

## W34 governed-execution envelope

```text
Agent definition
→ published state
→ identity / connection / policy
→ session evidence
→ durable change
→ build provenance
→ artifact attestation
→ admission policy
→ runtime
→ evidence lifecycle
```

This is an observatory synthesis, not a single published Agent protocol

**Durable rule:** runtime admission can be machine-enforced from provenance evidence, while Agent authority and ongoing runtime trust remain separate concerns
