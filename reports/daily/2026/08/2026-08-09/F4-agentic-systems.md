# F4｜Agentic Systems / 智能体系统

## Layer map

| Layer | Current signal |
|---|---|
| Tool/context access | MCP 2026-07-28 |
| Agent collaboration | A2A 1.x |
| Discovery/reachability | DNS-AID |
| Identity/authorization | NIST/NCCoE work |
| Evidence/conformance | TCKs, trajectory evaluation, observability |

## Judgment

The ecosystem should stop asking which single protocol “wins” and instead ask which combinations form coherent deployment stacks

MCP, A2A, and discovery systems can coexist because they address different boundaries. Competition will still occur in overlapping metadata, security, lifecycle, and governance layers
