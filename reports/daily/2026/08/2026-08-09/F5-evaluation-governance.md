# F5｜Evaluation & Governance / 评测与治理

## Finding

NIST continues to frame agent adoption around standards, open protocols, identity, authorization, security research, and evaluation. The NCCoE identity project is reviewing public comments rather than presenting a finished universal solution

## Analysis

Three different evidence questions must remain separate:

1. **Conformance** — does the implementation follow the protocol contract
2. **Reliability** — does the agent accomplish the task under realistic conditions
3. **Authority compliance** — did it stay inside delegated permissions and escalation rules

A system can pass the first and fail the other two

## Watch

Look for evaluation methods that jointly record protocol events, authority propagation, tool use, handoffs, failure recovery, and human takeover
