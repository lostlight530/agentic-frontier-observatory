# F3｜Compute, Data, and Infrastructure

Web Bot Auth turns edge infrastructure into an agent-identity verifier

Operational components include:

- HTTP Message Signatures
- key directories / JWKS
- Signature-Agent metadata
- freshness and expiration
- anti-replay considerations
- key rotation
- CDN / WAF / origin verification

This is identity infrastructure at the request boundary rather than only in a cloud IAM directory
