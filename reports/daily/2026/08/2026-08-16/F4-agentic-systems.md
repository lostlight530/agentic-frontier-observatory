# F4｜Agents, Runtimes, Harnesses, and Protocols

## W33 trust stack

```text
capability
→ governed discovery
→ agent principal
→ authentication / request provenance
→ delegated user scope
→ trust-domain boundary
→ policy interpretation
→ action
→ audit / revocation / evaluation
```

This stack is an observatory synthesis, not a single published protocol

MCP and A2A remain interoperability layers; identity, authorization, delegation, and cross-domain trust remain separate concerns around them

**Durable rule:** protocol compatibility does not automatically transfer authority, accountability, or trust
