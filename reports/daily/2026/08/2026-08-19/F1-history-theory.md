# F1｜History, Theory, and Paradigms

Agent governance is beginning to reuse mature software-engineering institutions rather than inventing governance from zero

Version control, commit authorship, pull requests, reviews, checks and merge decisions already provide durable change-control objects

The new move is to bind Agent session evidence into that existing institutional machinery

**Judgment:** mature Agent governance may advance fastest where autonomous work can inherit pre-existing human review and change-control structures
