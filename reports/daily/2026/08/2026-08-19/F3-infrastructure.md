# F3｜Compute, Data, and Infrastructure

Durable provenance requires stable linkage across multiple stores:

- task / issue identity
- Agent session identity
- session logs
- commit identity
- pull request identity
- review / checks
- audit history

A broken link anywhere in this chain weakens later incident reconstruction

**Open infrastructure problem:** portable correlation identifiers across Agent runtimes, MCP/A2A calls, version-control objects and audit systems
