# F4｜Agents, Runtimes, Harnesses, and Protocols

A coding Agent should be modeled as both an execution process and a producer of reviewable artifacts

```text
session
→ durable artifact
→ review boundary
→ integration decision
```

The important new layer is not another Agent protocol; it is the binding between runtime evidence and durable change-control objects

**Open question:** whether equivalent provenance bindings emerge for non-code Agents that modify tickets, documents, CRM records, cloud infrastructure or financial workflows
