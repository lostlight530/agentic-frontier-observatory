## 3｜Critical Developments / 关键变化

### 3.1 Freshness itself requires verification

**FACT** — The A2A official community hub lists “End-to-end evaluation of multi-agent systems on Vertex AI” as an “August 7” item

**FACT** — The linked original Google Developer Forum article shows publication on 6 August 2025

**ANALYSIS** — A durable observatory must never infer year, freshness, or event chronology from a hub label alone. Source traversal is part of the research, not clerical overhead

### 3.2 Multi-agent evaluation is a system problem

The original Google article evaluates not just final responses but reference trajectories and tool-call sequences, including exact match, ordered match, precision, and recall

This reinforces a long-term direction: once agents collaborate, the correct unit of evaluation is increasingly the full path of delegation, handoff, tool use, and result production

### 3.3 MCP and A2A remain complementary but architecturally different

A2A’s current official documentation explicitly frames:

- MCP as the agent-to-tool/context layer
- A2A as the agent-to-agent communication and collaboration layer

Recent implementation-grounded research from July 2026 reaches a similar but more nuanced conclusion: MCP can support constrained inter-agent coordination with lower protocol complexity, while A2A provides richer native stateful task and lifecycle abstractions at the cost of greater coordination complexity

This is not a winner-take-all protocol race

### 3.4 Identity and authorization remain unresolved infrastructure

NIST’s identity and authorization work continues to ask how existing identification, authentication, authorization, and enterprise standards should adapt to agents that access tools, data, applications, and other agents

The question has moved beyond “can the agent call the tool” to:

```text
Who is the agent
Who delegated authority to it
What may it do
How far may that authority propagate
How is the action attributed and audited
```

## 4｜Workstream Findings / 分任务发现

No paradigm break was found today. The agentic turn still looks like a systems-integration phase built on earlier symbolic, statistical, neural, and software layers

No model release identified in today’s authoritative-source pass changes the repository’s model-versus-system judgment

Evaluation infrastructure is becoming part of agent infrastructure. The ability to reconstruct trajectories and handoffs matters alongside serving, sandboxing, and observability

### F4 Agentic systems

A2A 1.0 remains a stable agent-to-agent layer and is explicitly positioned as complementary to MCP rather than a replacement

### F5 Evaluation and governance

The strongest signal today is evaluation granularity: final-answer quality is insufficient for multi-agent systems because incorrect delegation can invalidate a correct downstream component

### F6 Ecosystem and society

The ecosystem is beginning to institutionalize not only protocols but the methods used to decide whether a multi-agent system is trustworthy enough to deploy
