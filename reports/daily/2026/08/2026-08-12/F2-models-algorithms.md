# F2｜Models, Algorithms, and Multimodality

## Stable finding

Model intelligence and authorization remain orthogonal

A stronger reasoning model does not deserve broader permissions by default, and model upgrades should not silently expand an existing agent identity's authority

Today's identity evidence therefore strengthens a model/system separation:

```text
Model capability
≠
Agent identity
≠
Granted authority
```

No same-day model release before the cut-off changes the broader model trajectory today
