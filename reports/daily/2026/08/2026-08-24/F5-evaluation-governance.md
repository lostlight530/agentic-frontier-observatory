# F5｜Evaluation, Safety, Governance, and Standards

W35 begins with seven falsifiable hypotheses rather than a new standards claim

The key evaluation distinction is temporal:

```text
admission evidence
≠
ongoing runtime compliance
```

NIST provides a general architecture in which ongoing sessions can be continued, limited, or revoked; GitHub provides artifact admission and evidence lifecycle primitives; SPIFFE provides short-lived workload identity

**Boundary:** none of these alone proves an Agent-specific end-to-end revocation system
