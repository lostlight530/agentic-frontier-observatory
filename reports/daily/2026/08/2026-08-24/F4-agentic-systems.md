# F4｜Agents, Runtimes, Harnesses, and Protocols

## W35 runtime-trust model

```text
Agent definition / authority
→ admission evidence
→ runtime workload identity
→ session telemetry
→ policy re-evaluation
→ continue / limit / revoke
```

This is an observatory synthesis, not a published universal Agent protocol

MCP/A2A interoperability remains separate from runtime enforcement. A transport can continue to work even while authorization, identity, artifact trust, or policy state changes

**Question:** where is the enforcement point that can make those trust changes real?
