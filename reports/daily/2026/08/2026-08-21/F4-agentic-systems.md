# F4｜Agents, Runtimes, Harnesses, and Protocols

W34 now spans a complete execution-and-delivery path:

```text
Agent definition
→ runtime session
→ durable source change
→ reviewed integration
→ build artifact
→ attestation
→ admission policy
→ runtime
```

This remains an observatory synthesis

MCP / A2A solve interoperability concerns; Sigstore / SLSA / admission controllers solve software provenance and policy enforcement concerns; Agent authority remains a separate layer that still needs mapping

**Durable candidate:** supply-chain enforcement is a substrate for accountable Agent delivery, not a substitute for Agent authorization
