# F2｜Models, Algorithms, and Multimodality

No same-day model release before the observation cut-off changes the broader trajectory

The relevant distinction today is between model-generated source and the software artifact eventually delivered to users

A stronger coding model can improve source generation, but it does not itself establish which workflow produced a package or container, whether that artifact corresponds to the reviewed commit, or whether the artifact remained unchanged after build

**Rule:** model capability and artifact provenance are separate evidence domains
