# F1｜History, Theory, and Paradigms

W34 is shifting the unit of analysis from an Agent action to an evidence chain that survives multiple lifecycle transitions

```text
task intent
→ execution
→ source change
→ review
→ build
→ artifact
→ consumption
```

Historically, mature automation becomes governable when evidence remains meaningful after the original actor or process has disappeared

**Judgment:** accountable agency requires evidence continuity, not only execution visibility
