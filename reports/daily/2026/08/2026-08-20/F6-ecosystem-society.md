# F6｜Open Source, Industry, Economy, and Society

Portable build provenance reduces the need to trust a producer only by reputation: consumers can inspect machine-verifiable claims about where and how an artifact was built

For Agent-produced software, this raises a new ecosystem expectation: output should increasingly carry evidence that survives vendor boundaries and organizational handoff

But provenance infrastructure can also create false confidence if consumers treat a valid attestation as proof of software safety or correct authorization

**Boundary:** trustworthy evidence infrastructure does not eliminate downstream judgment
