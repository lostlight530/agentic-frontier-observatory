# F4｜Agents, Runtimes, Harnesses, and Protocols

## Core distinction

Core products are absorbing generic action capability while open protocols remain responsible for connecting independent systems

```text
Native action
→ browser / computer / tools

Open interoperability
→ MCP tool and context access
→ A2A agent collaboration
→ discovery
→ identity and authorization
```

A2A's Agent Card explicitly carries identity, service endpoint, capabilities, and authentication requirements; its project also maintains Inspector and TCK tooling

The open question is whether these layers can interoperate with the permission systems of increasingly powerful core products
