# F3｜Infrastructure / 基础设施

## Result

Agent infrastructure is expanding beyond serving and sandboxes into routing, cacheability, observability, and trajectory reconstruction.

The 2026-07-28 MCP specification is a strong current anchor: its stateless core, header-based routing, cacheable lists, authorization hardening, extension framework, and updated Tier 1 SDKs make ordinary web infrastructure more directly usable for agentic workloads.

## Analysis

Infrastructure now shapes behavior. Routing, identity metadata, cache semantics, task extensions, and deprecation policy are no longer implementation trivia; they influence reliability and governance.
