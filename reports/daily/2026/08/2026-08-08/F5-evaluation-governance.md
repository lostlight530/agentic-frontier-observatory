# F5｜Evaluation & Governance / 评测与治理

## Result

Today’s strongest durable signal is that agent evaluation is becoming system-level infrastructure.

A2A’s roadmap explicitly lists validation tooling such as the Inspector and Technology Compatibility Kit. NIST’s AI Agent Standards Initiative separately treats standards, open protocols, security evaluation, identity, authentication, and authorization as core pillars.

## Judgment

For multi-agent systems, final-answer correctness is insufficient. Evaluation must increasingly inspect delegation, task lifecycle, tool calls, authority boundaries, recovery, and traceability.
