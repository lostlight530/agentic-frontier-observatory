# F4｜Agents, Runtimes, Harnesses, and Protocols

## Governed execution model

```text
agent definition
→ draft
→ publish
→ access / audience
→ connection identity
→ tool / connector scope
→ runtime approval / constraint
→ trigger
→ execution
→ audit / analytics / revocation
```

This model is an observatory synthesis, not a single protocol

OpenAI Workspace Agents, GitHub Agent Control Plane, and Microsoft Entra Agent ID each expose different slices of this stack
