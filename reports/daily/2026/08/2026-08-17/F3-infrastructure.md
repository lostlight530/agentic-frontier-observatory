# F3｜Compute, Data, and Infrastructure

Workspace-level governance adds infrastructure dimensions that sit above raw compute and below business workflow

Relevant primitives now include:

- draft / published-state boundary
- role-based access
- scoped trigger tokens
- end-user versus agent-owned connection identity
- schedule / API / channel triggers
- write approval
- action-parameter constraints
- audit and version history

**Open problem:** these controls are still largely platform-local and are not yet a portable cross-vendor execution envelope
