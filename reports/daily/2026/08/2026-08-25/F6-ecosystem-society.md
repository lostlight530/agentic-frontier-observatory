# F6｜Open Source, Industry, Economy, and Society

W35 exposes a portability problem beneath enterprise Agent governance

A vendor can implement fast revocation where it controls the identity issuer, resource provider and policy loop

Cross-vendor Agent systems distribute those roles across clouds, MCP servers, SaaS tools and local runtimes

**Strategic question:** can open protocols carry revocation-relevant state without forcing every resource into one vendor-specific control plane?
