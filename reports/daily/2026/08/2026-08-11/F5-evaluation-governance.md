# F5｜Evaluation, Safety, Governance, and Standards

GitHub Agent Finder demonstrates an important operational rule: discovery can be automated while installation remains explicit

Enterprise-managed settings can also restrict which resources are visible and usable

This gives the governance chain a clearer order:

```text
Can the agent see it?
→ Is the resource allowed?
→ Is this user/agent authorized?
→ May it be connected now?
→ What actions are permitted?
→ What evidence is recorded?
```

Evaluation must eventually test mistakes at every layer, not only task completion
