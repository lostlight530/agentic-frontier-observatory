# F4｜Agents, Runtimes, Harnesses, and Protocols

The Agent governance chain now includes evidence lifecycle after admission

```text
Agent session
→ source change
→ build
→ artifact attestation
→ admission
→ evidence lifecycle
→ re-evaluation
```

Agent authority still remains a separate concern: revoking build provenance is not equivalent to revoking delegated business authority, cloud credentials, MCP access, or an A2A relationship
