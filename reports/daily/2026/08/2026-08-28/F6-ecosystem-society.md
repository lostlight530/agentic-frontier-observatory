# F6 — Open Source, Industry, Economy, Society

## Finding

The ecosystem signal today is not a new vendor feature but convergence pressure

As Agents become long-running and asynchronous, users and operators need recovery semantics that survive process boundaries and vendor boundaries

A2A and MCP now both expose durable task identity concepts, but their recovery semantics remain different and incomplete

This creates a likely interoperability pressure point:

```text
vendor session IDs
↕
open task IDs
↕
incident / audit IDs
```

## Boundary

Shared vocabulary around tasks does not yet equal cross-vendor recovery interoperability
