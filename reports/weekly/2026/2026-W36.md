## 1｜Opening Judgment / 开周判断

W35 established that recovery needs a distinct successor execution and independent authorization.

31 August refines the next problem:

```text
A2A generic referenceTaskIds exists
↓
but generic relation ≠ typed recovery lineage
↓
and referenced object ≠ ambient read authority
```

W36 therefore studies how relationships, authority and incident correlation compose without semantic collapse.

## 2｜Carry-Forward from W35 / 从 W35 延续

## 3｜Monday Correction / 周一纠偏

The protocol already has a generic contextual relation:

`Message.referenceTaskIds`

So the W36 question is **not** whether references exist.

It is whether they can become interoperably typed:

```text
references
├─ predecessor
├─ supersedes
├─ repairs
├─ compensates
└─ incident-member
```

The A2A Java SDK 1.2.0.Final release adds an independent security constraint: referenced-task lookup must respect read authorization.

## 4｜Opening Hypotheses / 开周假设

### H36-1 — Generic references evolve into typed recovery lineage

**Strengthener:** normative relation type, extension/profile, TCK or cross-vendor implementation.  
**Falsifier:** mature recovery works reliably with only untyped references and local conventions.

### H36-2 — Referenced Task access remains independently authorized

**Strengthener:** consistent read/operation authorization across SDKs and transports.  
**Falsifier:** secure mature systems can expose referenced Task state without separate authorization.

### H36-3 — Incident correlation becomes portable across execution namespaces

**Strengthener:** trace/incident ID spanning A2A, MCP and vendor sessions/remediation.  
**Falsifier:** reliable reconstruction requires no shared correlation mechanism.

### H36-4 — Exception / break-glass becomes a lifecycle object

**Strengthener:** owner + reason + scope + expiry + audit evidence.  
**Falsifier:** mature systems safely scale unstructured permanent bypasses.

### H36-5 — Non-code outputs gain explicit remediation semantics

**Strengthener:** withdraw / supersede / compensate primitives for documents, messages, tickets, CRM, datasets or infrastructure.  
**Falsifier:** consequential non-code output remains safely governable without persistent remediation state.

## 5｜Durable Starting Boundaries / 本周默认边界
