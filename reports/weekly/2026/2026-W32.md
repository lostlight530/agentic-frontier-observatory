## 3｜Most important weekly findings / 本周最重要发现

### A. The frontier is moving beyond model comparison

The durable research object is increasingly the whole agentic system: model + harness + tools + communication + discovery + identity + evidence + governance

### B. Protocol maturity is becoming operational

MCP’s stateless core and A2A’s stable SDK era show that protocol research must include routing, caching, SDK convergence, migration, TCKs, and deployment behavior

### C. Discovery deserves its own layer

DNS-AID makes the reachability problem explicit. An interoperable agent that cannot be securely discovered remains operationally isolated

### D. Identity and authority remain unresolved

NIST’s continued focus on identity and authorization confirms that delegated authority is not a solved by-product of existing web identity

### E. Evidence quality is part of infrastructure

The 8 August chronology correction and the need for conformance/trajectory evidence point to the same principle: an observatory and an agent system both need evidence that can reconstruct what actually happened
