## 2｜Week-opening signal — 2026-08-10 / 开周信号

OpenAI scheduled Atlas to stop working on 9 August 2026 while explicitly moving browser-based agentic capabilities into ChatGPT and Codex. Google had already moved computer use from a standalone Gemini 2.5 computer-use model into Gemini 3.5 Flash as a built-in tool.

This suggested a structural convergence: browser and computer action are becoming core product/model capabilities, while MCP, A2A, discovery, identity, and authorization remain the external coordination fabric.

## 3｜W33 priority questions / 本周优先问题

1. **Core-surface consolidation** — Do more agentic capabilities move into general AI products?
2. **MCP migration evidence** — How quickly do implementations converge on the 2026-07-28 specification?
3. **A2A conformance** — Do TCK, Inspector, SDKs, and cross-vendor implementations produce evidence beyond specification compatibility?
4. **Discovery and identity** — How do Agent Cards, DNS-AID, registries, ARD, and identity/authorization compose?
5. **Operational trust** — Can policy, approval, escalation, audit, and revocation cross runtime boundaries?
6. **Evaluation** — Can traces reconstruct delegation, authority, recovery, and human takeover?
7. **Broad AI coverage** — Keep models, compute, science, robotics, open source, labor, and governance in scope.

## 4｜Working hypotheses / 本周工作假设

### H1 — Agentic capability becomes native

Standalone action wrappers will increasingly be absorbed into core AI products and models.

**Falsifier:** independent agent surfaces sustain differentiated capabilities that core platforms cannot or do not absorb.

### H2 — The durable moat moves upward and outward

As computer/tool use becomes common, differentiation shifts toward harness reliability, enterprise context, authorization, evaluation, workflow integration, and capability governance.

**Falsifier:** model capability alone continues to explain most real deployment differences.

### H3 — Protocol success requires operational evidence

MCP, A2A, and adjacent standards will increasingly be judged by migration, conformance, identity, observability, discovery, and production failure handling rather than publication alone.

**Falsifier:** ecosystem adoption grows without operational tooling or trust infrastructure.

## 5｜Progress Check — 2026-08-11

### New evidence

ARD introduces a federated, domain-anchored discovery layer for agents, MCP servers, A2A Agent Cards, Skills, APIs, and other callable resources. Its canonical specification remains **v0.9 Draft** and already includes conformance tooling.

GitHub Agent Finder provides implementation evidence: it queries a selected public or private registry, respects managed enterprise settings, ranks resources for a task, and explicitly does **not** auto-install discovered resources.

### Hypothesis status

| Hypothesis | Status | 11 Aug evidence |
|---|---|---|
| H1 — capability becomes native | **SUPPORTED / unchanged** | No new evidence today materially changes the 10 Aug platform-consolidation signal |
| H2 — moat moves upward/outward | **STRENGTHENED** | Discovery, registry governance, policy scope, provenance, and ranking emerge as independent infrastructure |
| H3 — operational evidence matters | **STRENGTHENED** | ARD includes conformance tooling; Agent Finder demonstrates policy-scoped behavior rather than only a written spec |

### Weekly model refinement

The outward path is now more precise:

```text
Resource Publication
→ Federated Discovery / Registry
→ Ranking & Policy Scope
→ User / Organization Selection
→ Authorization
→ Invocation via MCP / A2A / API
→ Identity & Audit
→ Conformance / Evaluation / Governance
```

The new weekly rule is explicit:

> **Discovery ≠ Authorization ≠ Invocation**

### New W33 questions

- Can ARD records, DNS-AID, A2A Agent Cards, and MCP registries compose without collapsing organizational policy boundaries?
- Can authority/trust requirements be represented in machine-verifiable discovery metadata before invocation?
- Who audits ranking, provenance, and freshness in federated agent-resource discovery?
