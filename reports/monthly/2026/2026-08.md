### W33 — accountable agency gets a trust stack

Discovery, Agent principals, request provenance, delegated scope and trust-domain boundaries became separate observable layers.

### W34 — governance enters execution

### W35 — trust remains live after admission

Resource re-evaluation, explicit runtime stop, residual-state reconciliation, terminal Task semantics, successor execution and request authorization extended the model through recovery.

### 31 August — reference is not authority

A2A normative definitions confirm a generic `referenceTaskIds` primitive for additional context.

A2A Java SDK 1.2.0.Final, published 7 August and first observed by this repository on 31 August, documents a security hardening that enforces read authorization on referenced-task lookups.

The open gap is therefore refined from “does cross-task reference exist?” to “does typed, interoperable recovery lineage exist?”
