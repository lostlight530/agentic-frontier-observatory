# Code of Conduct / 行为准则

## 中文

本准则适用于本仓库的 Issue、Pull Request、Review、Discussion 及其他公开协作。

参与者应保持专业、尊重和证据导向：批评事实、来源、方法和分析，而不是攻击个人；明确区分事实、外部主体声明、本仓分析、推断与未知状态；尊重隐私、署名、版权和第三方许可。

不接受骚扰、歧视、威胁、人肉搜索、冒充、伪造证据、故意误导、重复扰乱讨论，或将草案、营销声明和未验证结果包装成已实现事实。

请勿公开凭据、私人通信、个人数据、未公开漏洞细节或其他敏感材料。安全问题按 `SECURITY.md` 处理；涉及私人信息的行为问题应通过可用的私密联系渠道处理，而不是公开 Issue。

维护者可以对违反本准则或破坏仓库证据完整性的内容进行编辑、隐藏、删除、锁定或拒绝。仓库所有者保留最终 moderation 与 merge authority。

## English

This code applies to Issues, pull requests, reviews, Discussions, and other public collaboration around this repository.

Participants should communicate professionally and respectfully, critique facts, sources, methods, and analysis rather than people, distinguish facts from attributed external claims and repository analysis, keep uncertainty explicit, and respect privacy, attribution, copyright, and third-party licenses.

Harassment, discrimination, threats, doxxing, impersonation, fabricated evidence, deliberate deception, repeated disruption, or presenting drafts and unverified claims as established facts are unacceptable.

Do not publish credentials, private communications, personal data, unpublished exploit details, or other sensitive material. Follow `SECURITY.md` for security-sensitive reports. Conduct concerns containing private information should use an available private contact route rather than a public Issue.

The repository maintainer may edit, hide, remove, lock, or reject contributions that violate these standards or materially undermine repository integrity. The repository owner retains final moderation and merge authority.
