# Security / 安全说明

## 中文

本仓库保存公开研究材料，不运行外部项目，不托管密钥，不提供网络服务，也不执行第三方代码。

请勿在 Issue、PR 或报告中提交：

- API 密钥、访问令牌或账户凭据
- 私人通信、未授权个人数据或内部文件
- 未公开漏洞利用细节
- 受版权保护材料的完整复制

发现仓库本身存在敏感信息泄露或供应链问题时，请使用 GitHub 私密安全报告渠道。

## English

This repository stores public research material. It does not run external projects, host secrets, expose a network service, or execute third-party code.

Do not submit credentials, private communications, unauthorized personal data, unpublished exploit details, or full copies of copyrighted material. Use GitHub's private security reporting channel for repository-level disclosure.
