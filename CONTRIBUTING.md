# Contributing / 贡献指南

## 中文

本仓库接受能够提升事实准确性、来源质量、时间校准和分析边界的贡献。

贡献应当：

- 优先引用一手、官方或原始研究来源
- 明确区分事件发生日期、发布日期和本仓观察日期
- 区分事实、外部主体声明和本仓分析
- 对不确定、冲突或无法确认的内容显式标注
- 避免把草案、路线图、演示或营销声明写成已经实现的能力
- 不提交凭据、私人信息、付费内容全文或无法公开核验的材料

本仓库不接收以运行结果、性能复现或产品体验替代来源分析的贡献，因为能力验证不属于本仓库职责。

## English

This repository welcomes contributions that improve factual accuracy, source quality, date calibration, and analytical boundaries.

Contributions should:

- Prefer primary, official, or original-research sources
- Separate event date, publication date, and repository observation date
- Distinguish facts, external claims, and repository analysis
- Mark uncertainty, conflicts, and unverifiable material explicitly
- Never present drafts, roadmaps, demos, or marketing claims as implemented capability
- Never submit credentials, private information, full paywalled content, or non-public evidence

Capability testing, benchmark reproduction, and product validation are outside this repository's scope.
