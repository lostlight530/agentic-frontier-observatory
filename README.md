## Evidence Model / 证据模型

Every material statement should remain identifiable as one of:

- **FACT / 事实** — directly supported by a cited source;
- **EXTERNAL CLAIM / 外部声明** — attributed to a company, author, institution, or project;
- **ANALYSIS / 本仓分析** — synthesis or inference produced by the observatory;
- **UNCERTAIN / 不确定** — evidence is insufficient, stale, ambiguous, or conflicting.

Source authority does not remove the need to calibrate exact version, date, scope, and maturity.

```text
specification exists != interoperable deployment
product documentation exists != capability validated
benchmark claim exists != benchmark reproduced
protocol publication != operational maturity
current-state confirmation != same-day state transition
```

## Research Discipline / 研究纪律

```text
Capability != Deployability
Discovery != Authorization != Invocation
Identity != Credential != Authority
Authenticated Origin != Delegated User Authority
Transport Interoperability != Trust Interoperability
Protocol Publication != Operational Maturity
Admission != Continuous Authorization
Resource Denial != Runtime Stop
Runtime Stop != Rollback
Termination != Remediation
Context Continuity != Authority Continuity
```

These distinctions are research boundaries, not rankings or predictions.

## Publication and Citation / 出版与引用

The DOI above identifies an archived software publication of this observatory. It provides a stable citation target for that archived publication.

The repository's own DOI is **not** an observed-world source and is not independent corroboration for an external technology, organization, standard, product, or policy claim.

```text
repository publication identity != observed-world evidence
repository DOI != independent source
archived publication != later current main
citation count != evidence independence
```

When citing a time-sensitive research conclusion, use the relevant report/source record and its observation boundary in addition to any repository-level software citation.

## Research Production and Repository Governance

The Daily / Weekly / Monthly SOP files define the production cadence for time-ordered research outputs. They are separate from the durable methodology and repository identity described here.

Repository contribution, maintenance, and external-review materials live under the corresponding contribution/governance surfaces and do not become part of the evidence chain merely because they are stored in the same repository.
